
## 增补（同日）：报告深度要求

- 报告采用章节制，HTML 章节 ≥ 10，PDF 页数 ≥ 10（reportlab 渲染升级为标题/表格 flowables，验收可程序化断言）。
- 演示数据源扩至 25-30 条帖子（4 平台 × 多情绪 × 互动指标），Agent 结构化产出新增：整体/分渠道情绪占比、渠道声量分布、热门帖子榜——为报告提供真实数据密度。
- 图表用 ECharts（HTML 报告 CDN 引入）；PDF 走 reportlab 文本重排，不受前端图表影响。
- 接入真实 API key 时，章节分析文字由真实模型撰写，报告在数据饱满之上获得观点深度；mock 路径保证无 key 时的最小可演示性。
