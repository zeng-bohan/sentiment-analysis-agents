# ADR 0002: 演示范围跳过前端单测，以真实链路验收

日期：2026-08-25
状态：已采纳

## 背景

任务控制台是时间盒 2-3 小时的演示项目。流水线默认 TDD，但 React 组件测试对该规模性价比低，且后端已有完整测试套件守护 API 行为。

## 决策

- 不编写前端组件/单元测试。
- 验收 seam 只有一个：**后端以 `mock_llm` 模式运行时的真实 HTTP API**。每张票的完成定义是「在 mock 链路上人工走查对应场景通过」。
- 后端代码与后端测试零改动。

## 后果

- 前端回归依赖人工走查，若控制台演变为长期维护的产品，需重新引入组件测试并作废本 ADR。
